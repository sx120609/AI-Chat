# Responses 任务工作台

Web chat 以一次任务组织多轮工具调用、执行进度和成果。`/chat`、`/beta` 共用执行底座。手机端参考 CPU-web 的 `HomeMobile.vue`：青绿强调色、紧凑快捷入口、卡片列表和分段筛选，提供任务、历史、成果三个入口。

## 升级

在部署环境完成数据库备份后，先执行以下增量升级，再切换应用版本：

```sh
npm ci
npm run db:responses-workspace
npm run build
```

脚本读取部署环境的 `DATABASE_URL`，只添加 Message 的原生状态、心跳、停止标记和 AiSettings 的工具配置字段；使用事务和锁等待上限，重复执行不会清除旧数据。旧消息仍可读取。回退应用时可保留新增列。

## 工具设置

管理员在工具设置中配置 Responses 原生工具：文本成果默认启用；托管代码执行、图片生成和文件检索默认关闭。通过模型 ID 白名单限制支持范围，通过单独费率设置计入实际工具费用。启用托管工具前应确认对应上游支持并配置费用。共享 vector store 对该配置下的用户可检索，应只配置允许共享的资料库。

文本成果支持 Markdown、CSV、HTML、SVG、JSON、代码等。Office、PDF 等二进制成果必须由真正的代码执行工具生成，不能用改文件扩展名代替。生成文件会复制到本站附件存储，归属用户、会话和项目。HTML/SVG 在隔离 iframe 中预览，不能访问站点会话或发起网络请求。

## 执行与状态

- 保存完整 Responses output items，保留函数调用和加密推理状态；浏览器只获取可展示的进展、成果和引用。
- 继续任务会重放相同上游、密钥和模型范围内的原生状态；切换范围时使用文本与附件上下文。中断的函数调用会补明确的失败结果，避免悬空调用阻塞续聊。
- 每轮任务最多 12 次模型请求、24 个文本成果，文本成果合计上限 2,000,000 字符，单个文本 500,000 字符；上游文件保存遵循现有附件大小限制。
- 汇总多轮 token usage、去重的搜索调用和配置的托管工具费用后结算。
- 普通任务在浏览器断开后继续执行并持久化，重新打开会话会轮询恢复。停止按钮通过服务端停止标记取消任务。编辑和重新生成创建分支，保留原任务。
- 运行依赖持续存活的 Node 服务进程。服务重启不会自动重启上游任务；超过两分钟无心跳的任务在回读时标记中断并保留已有成果。临时任务不持久化，关闭连接会停止。
- 上下文超限时保留近期完整轮次，历史记录仍在数据库；本版不调用上游 compaction，也不承诺无限上下文。

## 验证

```sh
npm test
npx tsc --noEmit
npm run lint
npx prisma validate
npm run build
```

本次另使用隔离 PostgreSQL 和模拟 Responses 上游完成请求/浏览器检查：多轮成果生成、版本修订、刷新恢复、断线后继续、显式停止、异常流、私有下载、跨用户隔离、Markdown/HTML 预览与下载。移动端检查覆盖 320/390/768 像素的首页、历史搜索与成果入口，桌面检查为 1440 像素。

这些检查不代表生产上游已经支持或通过托管工具验收；正式启用后还需对真实上游核对代码执行、图片生成、vector store 权限及账单。本次没有执行生产部署。
